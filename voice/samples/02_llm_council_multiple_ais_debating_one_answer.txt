Topic: LLM Council (Multiple AIs Debating One Answer)

What if ChatGPT asked multiple AIs before it gave you an answer? You know normally when you ask ChatGPT a question, the answer you get usually comes from one model, but we all know AI can make things up. So this guy built something called LLM Council, and with this tool, instead of asking one AI the question, it asks multiple AIs the same question, they review each other's answers, and do some kind of ranking, and the new AI combines the best part into one very strong response. So it's like a board meeting of AI, and I strongly think this is how serious AI systems will work going forward. Obviously, having a system like this will cost you more because you're calling multiple models, but when making a better decision, having five AIs debating each other is way better than trusting one.
